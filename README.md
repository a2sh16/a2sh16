### [Alpha Pipeline](https://github.com/a2sh16/alpha-pipeline) — AI Stock Signal Platform
Real-time trade signals derived from government data (Congressional disclosures, SEC Form 4, 13F filings). Built with React 19, tRPC, GPT-4o, Stripe, and a Kotlin Android app. Live at [alphapipe-a5fxt9gi.manus.space](https://alphapipe-a5fxt9gi.manus.space).

### [SignalDesk](https://github.com/a2sh16/signaldesk) — Autonomous Real Estate Deal Acquisition
Monitors 20+ distress signals nationwide, scores every property 1–100, and generates AI investment briefs with ARV and exit strategies. Includes a Chrome Extension overlay for Zillow/Redfin.

**Stack:** Next.js 15 · FastAPI · Python · Supabase · PostgreSQL · GPT-4o · Stripe · Twilio · MV3 Chrome Extension
